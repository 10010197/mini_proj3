## Part 1. 제공 데이터 구성

### 1.1 파일 구성
| 파일 | 수집 키워드 | 행 수 | 비고 |
|---|---|---|---|
| `04_바이오헬스_키워드_바이오의약품_…csv` | 바이오 의약품 | 6,580 | |
| `04_바이오헬스_키워드_디지털헬스케어_…csv` | 디지털 헬스케어 | 25,991 | |
| `04_바이오헬스_묶음_바이오헬스케어_…csv` | 두 키워드 | 32,454 | **두 파일의 합집합** (동시 수집 117건) |

- 세 파일 합계 65,025행이지만 **고유 문서는 32,452건**. 묶음 파일만 써도 정보 손실이 없다.
- 컬럼 7개: `제목, 본문전문, 원문URL, 발행일, 매체명, 문서종류, 수집키워드`
- `문서종류`는 전부 `news`. 즉 **제공 데이터는 뉴스 한 종류(현재 시점 근거)뿐**이며, 특허·공시·보고서는 직접 수집해야 한다.
- 파일명이 macOS NFD 유니코드라 Windows에서 그대로 매칭되지 않는다 → NFC 정규화 필요.

### 1.2 기간·분량
- 기간: 2021-10-17 ~ 2026-10-16 (5년). 2021년은 2.5개월분, 2026년은 9.5개월분.

| 연도 | 2021* | 2022 | 2023 | 2024 | 2025 | 2026* |
|---|---|---|---|---|---|---|
| 기사 수 | 1,204 | 6,011 | 6,539 | 5,741 | 7,502 | 5,457 |
| 바이오 의약품 비중 | 29% | 24% | 22% | 23% | 18% | 14% |

- 분기 공백 없이 고르게 분포 → **시계열 질문("최근 2년간 …")에 쓸 수 있다.**
- 키워드 비율은 디지털 헬스케어 : 바이오 의약품 ≈ **4 : 1**이고, 최근으로 올수록 바이오 의약품 비중이 줄어든다.

### 1.3 출처(매체)
- 106개 매체, **상위 10개가 52%** (머니투데이·뉴시스·전자신문·이데일리·뉴스1 …).
- URL은 네이버 뉴스 경유 (`n.news.naver.com` 96%, 구형 `news.naver.com`, 연예·스포츠 섹션 일부).
  URL 형식이 여러 가지라 **언론사ID+기사ID(oid/aid)로 문서 ID를 만든다.**
- 원 기사 URL이 아니라 포털 URL이므로, 답변의 출처 링크는 네이버 기사로 연결된다.

## Part 2. 제공 데이터 품질

### 2.1 결측·형식
| 항목 | 결과 |
|---|---|
| 결측 | 본문만 0.05% (17건) 비어 있음. 나머지 컬럼은 결측 없음 |
| 날짜 | 파싱 실패 0건, 분 단위까지 있음 |
| URL 중복 | 2건 (동일 URL 재수록) |
| 문서 ID | URL 형식이 다양해 oid/aid로 통일해야 함 |

### 2.2 본문 품질 문제
| 문제 | 규모 | 처리 |
|---|---|---|
| 포털 UI 텍스트 혼입 (`기사 섹션 분류 안내` 등) | **9,960건 (31%)** | 정규식으로 제거 |
| 저작권 문구 (`Copyrights`, `무단 전재`) | 76건 | 본문 끝에서 제거 |
| 짧은 본문 (300자 미만: 사진 캡션·속보) | 544건 | 제외 |
| 빈 본문 | 17건 | 제외 |
| 노이즈 제목 (`[포토]` 67, `[인사]` 등) | 101건 | 제외 (`[게시판]` 52건은 행사 일정 정보라 유지) |
| 연예·스포츠 섹션 | 66건 | 제외 |
| 주제 무관 (다른 의미의 `바이오`·`헬스케어`) | 414건 | 도메인 단어 3개 미만이면 제외 |

- 본문 길이: 중앙값 1,104자, 5%~95% 구간 481~3,028자. 1만 자 넘는 기사는 25건 (최대 22,496자) → **청크 분할은 필요하지만 대부분 1~3개 청크**.

### 2.3 중복
| 유형 | 규모 | 처리 |
|---|---|---|
| 파일 간 중복 (묶음 = 합집합) | 32,573행 | 문서 ID로 병합, 수집 키워드는 합침 |
| 본문 완전 중복 | 118건 | 제외 |
| 제목 중복 (같은 보도자료 재가공) | 814건 | 근중복 판정에 맡김 |
| 근중복 (MinHash 유사도 ≥ 0.8) | 약 1.5% | 지식베이스 선별 때 클러스터당 대표 1건 |

→ 같은 보도자료를 매체마다 다시 쓴 기사가 많아, **검색 결과 상위가 같은 내용으로 채워지는 문제**가 생길 수 있다. 인덱서(`dedup.py`)에서 임계값을 다시 조정할 예정이다.

### 2.4 선별 결과
```
65,025행 → 고유 32,452 → 품질 선별 31,192 → 지식베이스 7,997 (분기 층화 + 주제·전망 점수)
```
제외 사유와 건수는 `store/docs.db`의 `rejected_docs` 테이블과 `store/load_provided_stats.json`에 남아 있다.

### 2.5 시사점 (주제 B 관점)
1. **뉴스의 22%(6,843건)가 시장 규모·성장률 같은 전망 수치를 인용한다.** 대부분 보고서를 재인용한 것이라, 보고서 원문과 수치·시점이 어긋나는지 비교하기 좋다 → 상충 질문의 핵심 재료.
2. 뉴스는 **"무엇이 발표됐나"에는 강하지만**, "기술이 실제로 쌓이고 있나"(특허)나 "계약 조건이 뭔가"(공시)에는 약하다 → 시간축이 다른 출처가 필요한 이유.
3. 행사·MOU 기사가 많아, 동향 질문의 답이 **실질 사건보다 홍보성 기사로 채워질 위험**이 있다 → 검색 때 공시·특허 근거에 가중을 두거나 제휴성 기사의 점수를 낮춘다.
4. 매체 상위 10곳이 절반이라 특정 매체 관점에 치우칠 수 있다 → 답변에 매체 다양성을 표시한다.

## Part 3. 챗봇 사용자 및 업무 상황

### 3.1 사용자
| 사용자 | 소속 예 | 하는 일 | 챗봇에서 원하는 것 |
|---|---|---|---|
| **P1. 산업 분석가** (주 사용자) | 증권사 리서치, 산업연구 기관 | 섹터 보고서 작성, 기술·시장 동향 모니터링 | 주제별 동향을 **근거와 시점이 붙은 형태**로 빠르게 정리, 뉴스와 전망 수치의 차이 확인 |
| **P2. 사업개발(BD)·전략 담당자** | 제약·바이오 기업 | 라이선스 후보 탐색, 경쟁사 동향 파악 | 특정 기술·기업의 **기술이전·계약 이력**과 특허 출원 흐름 |
| **P3. 투자 심사역** | VC, 기업 CVC | 투자 검토용 시장·경쟁 분석 | 기사의 시장 전망이 **보고서·공시와 일치하는지** 검증 |
| **P4. 정책·사업 기획자** | 공공기관, 협회 | 규제·지원사업 기획 | 규제 변화(의료 AI, 비대면 진료)와 산업 반응의 연결 |

### 3.2 업무 상황
| # | 상황 | 사용자 | 빈도 | 필요한 근거 |
|---|---|---|---|---|
| S1 | **주간·월간 동향 브리핑 작성** — 특정 하위 주제의 최근 사건을 정리 | P1, P4 | 매주 | 뉴스(current) 중심 + 공시로 사실 확인 |
| S2 | **기술 성숙도 판단** — 뉴스에서 뜨는 기술이 실제로 특허가 쌓이고 있는지 | P1, P2 | 보고서 작성 시 | 뉴스(current) vs 특허(leading) |
| S3 | **시장 전망 수치 검증** — 기사 속 시장 규모·성장률의 출처와 다른 추정치 비교 | P1, P3 | 투자·보고서 검토 시 | 뉴스 vs 보고서(outlook), **상충 표시** |
| S4 | **기업·딜 사실 확인** — 기술수출·공급계약 규모, 상대방, 시점 | P2, P3 | 수시 | 공시(1차 근거) > 뉴스 |
| S5 | **규제·정책 영향 파악** — 제도 변화 전후 산업 반응 | P4, P1 | 제도 변경 시 | 뉴스 시계열 + 보고서 |

### 3.3 챗봇이 하지 않는 것 (범위 밖)
- 개별 종목 매수·매도 추천, 주가 예측 → 거절하고 근거 자료만 제시
- 의학적 효능 판단·진료 조언
- 지식베이스 기간(2021-10 ~ 2026-11) 밖의 최신 사건 → "자료 없음"으로 답한다

### 3.4 답변 원칙
1. 근거를 **출처 종류별(뉴스·공시·특허·보고서)로 나눠** 보여주고, 각 근거에 날짜·발행처·URL을 붙인다.
2. 시간축이 다른 근거가 엇갈리면 숨기지 않고 **"상충" 블록**으로 따로 표시한다 (무엇이, 언제 기준으로, 얼마나 다른가).
3. 공시 > 보고서 > 뉴스 순으로 1차성이 높다. 수치가 다르면 1차 근거를 우선하되 다른 값도 함께 적는다.
4. 근거가 부족하면 추정하지 않고 부족하다고 말한다.
